Zoltraak User Guide & Handbook

Zoltraak is a segmented download manager for Windows, multi-site video extractor, album harvester, and container remuxing workstation built with Rust and Tauri. Designed around the railway Dispatch Board aesthetic, Zoltraak prioritizes zero telemetry, atomic state persistence, parallel chunk acceleration, tokenized motion dynamics, and seamless browser synchronization.

Windows is the primary supported platform. Zoltraak can also run on Linux, but it has not yet been fully tested there.

01

Quick Start & Launcher

For an installed Windows copy, open Zoltraak from the Start menu or its application shortcut. The launch commands below are for a source checkout with the development prerequisites installed, rather than an installed release.

Source Checkout Launch Modes

Mode Command Description
Desktop App scripts\bat\run.bat or npm --prefix app run app:dev Launches full Tauri v2 desktop application with embedded engine supervisor and system tray integration.
Headless Engine scripts\bat\run.bat engine Runs background Rust API daemon bound to loopback 127.0.0.1:1450 (ideal for servers or background daemons).
Web UI Preview scripts\bat\run.bat web Starts the local engine if needed and runs the Vite development server for a browser preview.
Local Application Data

Zoltraak stores its database and settings in the local application data directory selected by the desktop runtime. It does not write to system roots, require administrative rights for standard execution, or phone home to any telemetry endpoints.

02

Architecture & Design Philosophy

Unlike legacy download utilities built on bulky Electron runtimes, Zoltraak separates high-performance networking from user interface rendering.

  • Rust Core Engine (zoltraak-core): Multi-threaded async I/O powered by Tokio, Hyper, and Reqwest with zero-allocation buffer streaming. Handles segmented byte-range chunking, hashing, and manifest parsing.
  • Localhost IPC / REST API (zoltraak-api): Bound strictly to the loopback interface (127.0.0.1:1450). External clients (like the browser extension) authenticate via cryptographically random pairing tokens.
  • Tauri v2 Desktop Shell: Ultra-lean native window utilizing OS system webviews. Consumes the engine directly via in-process IPC commands with zero HTTP latency.
  • Browser Companion Extension: Bridges Chrome, Edge, Brave, Firefox, and Zen Browser directly into Zoltraak. Captures downloads, injects video overlays, and synchronizes browser login sessions.

Dashboard & Queue Operations

The Downloads section represents the central dispatch board for all active, queued, and completed jobs.

Segmented Multi-Connection Acceleration

When you paste a URL or send a download from the browser, Zoltraak issues an HTTP HEAD request to check for byte-range support (Accept-Ranges: bytes). If supported, the engine splits the file into multiple equal segments and downloads them in parallel across up to 32 connections.

500 MB - 2 GB: 16 connections
> 2 GB:      24 to 32 connections

Register Columns Customizer

Zoltraak allows you to customize the register table directly from Settings → Appearance → Register Columns:

  • Column Reordering & Visibility: Choose which columns appear on the dispatch board (Checkbox, Name, Status, Size, Progress, Rate, ETA, Chunk Occupancy, Connections, Added Date, Actions).
  • One-Click Presets: Switch instantly between Default, Compact (focused on progress and speed), or Detailed telemetry.

Register Row Actions & Context Menu

  • Pause / Resume: Pauses stream chunk ingestion immediately, flushing incomplete byte segments safely to disk. Resuming reconnects using byte-range headers without re-downloading finished bytes.
  • Show in Folder (Reveal): Opens the destination directory and selects the finished file in your operating system's native file manager.
  • Open File: Opens the completed file directly with your operating system's default viewer/player.
  • Quick convert to MP4: Opens the completed video or audio file directly in the Convert tab for container conversion or codec transcoding.
  • Send to Discord: Delivers completed files directly to your configured Discord server channel or webhook. Works on individual rows or multi-selections to batch files together.
  • Delete Row: Removes the download record from Zoltraak's SQLite register.

Review Batches and Recover Failures

Paste several links into the bottom entry and select Review links. The review identifies repeated, existing, and invalid URLs, shows the download folder, and lets you select which links to add. Accepted links leave the draft; unsuccessful and unsubmitted links stay available for correction. Pasting outside an input opens the same entry. Dropped links start downloading immediately; a link that would save an HTML page instead of a file asks for confirmation first, and any link that cannot be added stays in the entry. A single video, post or music link offers to open in the Video, Posts or Music tab instead; decline to download it as a regular file.

Failed entries offer Retry download and the appropriate recovery action: share a browser sign-in, choose another folder, or try the alternative video extractor. Technical details can be expanded and copied. Choosing another folder prepares a new download and keeps the original failed entry.

Saved Views and Linked Notifications

The download search, filter, sort direction, row density, and column order are remembered across restarts. Use Arrange columns to move columns, choose their visibility, or reset the view. Sort by date, name, size, speed, or progress.

Notification history links completion and failure messages to their download entries. Select a linked notification to open and highlight its entries, filter with Errors only, or Retry failed downloads that are still failed. Nearby completion events from regular downloads, videos, and music are grouped, and all toast popups still expire automatically.

Deleting Entries and Downloaded Files

Right-click a download entry to choose Remove from list (keeps the finished file) or Delete entry and file. Individual trash buttons in Downloads, Video, and Music delete both by default. Turn off Settings → General → Behaviour → Delete local file with trash button to keep downloaded files instead. The six-second Undo window cancels the removal; file deletion is permanent when it expires. A file deletion error keeps the entry available for retry. Clearing completed history or a music collection keeps its finished files.

Celebration Confetti & Audio SFX

When downloads reach 100% completion, Zoltraak triggers a physical celebration confetti burst across the canvas. A dedicated audio sound effect (confetti-pop) plays alongside the burst. To prevent auditory and visual clutter, multiple downloads completing simultaneously are throttled so only a single celebratory burst fires. Both the confetti and its sound effect can be toggled independently under Settings → Appearance.

Notification Inbox & Badging

The top navigation bar features a notification bell with animated badge counters. The bell opens a persistent notification center containing download alerts, engine status updates, and Discord delivery results. You can configure the maximum number of retained notifications (1 to 200, default 25) in Settings → Appearance.

Video Downloader & Site Resolvers

The Video tab provides automated format extraction, stream resolution, and audio/video muxing for media sites.

Supported Platforms & Manifests

  • YouTube: Supports video watch URLs, Shorts, and Live streams. Decrypts player signatures, requests adaptive formats (1080p, 1440p, 4K, 8K), and handles browser proof-of-origin tokens (po_token).
  • X / Twitter: Resolves multi-rendition HLS manifests and highest-bitrate MP4 streams.
  • Instagram & TikTok: Extracts clean, watermark-free direct video feeds.
  • Facebook: Extracts high-definition progressive video files.
  • Generic Streams: Paste any .m3u8 (HLS) or .mpd (DASH) URL to analyze available quality ladders.

Quality Ladders & 1-Click Discord Auto-Send

When a page or manifest is analyzed, Zoltraak displays an interactive format ladder with available resolutions, codecs, and bitrates:

  • Download Video: Standard download button saves the format and automatically joins split audio/video streams using integrated FFmpeg.
  • Download and Auto-Send to Discord Companion Button: Positioned immediately beside each format download button, this Discord icon button downloads the format and automatically delivers the finished video to your configured Discord channel the moment it is ready. Live toast notifications confirm when the job is queued with auto-delivery.

Active & Completed Video Jobs

The jobs register beneath the format picker tracks download and muxing progress in real time. Each completed job provides one-click action icons:

  • Show in Folder: Reveals the completed video file in your native file manager.
  • Send to Discord: Re-delivers or shares the finished video directly to your connected Discord channel with one click.
  • Quick convert to MP4: Sends the video to the Convert tab for quick container swapping (e.g. MKV to MP4).
  • Delete Row: Removes the job record from Zoltraak's register (leaving the physical file intact on disk).
Automatic FFmpeg Staging

Modern platforms deliver high-definition video (1080p+) as split streams (separate video and audio feeds). Zoltraak downloads both in parallel and merges them seamlessly. You can install and verify FFmpeg with 1 click directly inside Zoltraak under Settings → General → FFmpeg Media Tools.

Posts & Gallery Extraction

The Posts tab allows you to paste social media post links and harvest every photo, carousel slide, and video clip into a unified gallery.

Original Resolution Fetching

Social feeds display downscaled, compressed previews to save bandwidth. Zoltraak inspects platform internals to retrieve the highest original file stored on the CDN:

  • X / Twitter: Photos are requested with name=orig parameter instead of feed thumbnails.
  • Instagram: Traverses display resources to select the maximum resolution candidate.
  • Reddit: Parses gallery metadata and fetches uncompressed assets in sequential order.

Recovering Hidden Facebook Photos

Facebook can expose only the visible preview tiles, even when the post contains more photos. Zoltraak tries the other known photo links and merges matching attachment data. If Posts still reports an incomplete set, use Open Facebook post, open its photo gallery, and view the remaining photos. Then right-click the post and choose Download post with Zoltraak again. The selected browser profile can share the gallery's attachment metadata with the local app. Refresh the Facebook tab after updating the extension so capture starts before the gallery loads. Partial results remain downloadable; a missing navigation link alone does not mean your sign-in has expired.

Magic Byte Sniffing & Format Verification

Before adding an image to the grid, Zoltraak inspects the file's first bytes (magic numbers):

Format Magic Header Bytes Protection Handled
JPEG FF D8 FF Verifies valid JFIF/EXIF data stream.
PNG 89 50 4E 47 0D 0A 1A 0A Prevents corrupted downloads from web firewalls.
WebP 52 49 46 46 ... 57 45 42 50 Fixes CDN path mismatches (e.g. WebP disguised as .jpg).
HTML Wall <!DOCTYPE html> DROPPED: Catches 200 OK login-walls so they are never saved as broken photos.

Batch Harvesting & 1-Click Discord Delivery

Selecting photos and clips in the gallery grid activates the harvest toolbar at the bottom of the view:

  • Download Selection: Hands the selected assets to the download register with clean naming (Post_Title_1.jpg, Post_Title_2.jpg, etc.) instead of messy CDN hashes.
  • Download and Auto-Send to Discord Companion Button: Located directly beside the download button in the toolbar, this companion button downloads all selected photos, carousels, and video clips and automatically packages them for Discord delivery in multi-attachment batches (up to 10 files per message).

Music Harvester & Audio Tagging

The Music tab transforms links from streaming services into cleanly tagged, high-fidelity audio files organized into album directories.

Supported Platforms & Stream Resolution

  • Catalogue Import: Paste track, album, playlist, or artist links from Spotify, Apple Music, or Deezer. Zoltraak reads the release metadata and matches recordings on YouTube Music by track title, artist, and duration with confidence scoring.
  • Direct Stream Resolvers: Direct links from YouTube, YouTube Music, SoundCloud, and Bandcamp stream audio directly without requiring catalogue matching.
  • Free-form Search: Type an artist and song name to search and download without needing a browser link.
  • Multi-Link Batch Queuing: Paste multiple URLs separated by newlines to queue an entire discography simultaneously.

Unavailable or Expired Streams

SoundCloud share links are expanded before analysis. If a full-length rendition is unavailable, Zoltraak tries the other supported renditions and refreshes stale metadata once. Generic music pages are checked again when their job starts. If a SoundCloud, Bandcamp or generic-page stream later returns an expired-link response, the app can refresh its source with at most two further download attempts. Switching renditions restarts the temporary audio file so different formats are never combined. Rate limits, removed tracks and access restrictions can still prevent a download; a raw signed audio URL needs a fresh link from its source when it expires.

Output Formats & Tagging Pipeline

  • Container Formats: Choose Best available (direct container pass-through without re-encoding: AAC → .m4a, Opus → .opus), or transcode to MP3, AAC/M4A, Opus, Ogg Vorbis, FLAC, ALAC, or WAV with selectable bitrates.
  • Automated Tagging: Writes ID3v2, MP4, and FLAC tags (title, artist, album, track/disc number, release date, genre, comments).
  • Embedded Cover Art: Embeds maximum-resolution artwork into MP3, M4A, and FLAC containers, and optionally saves cover.jpg alongside the tracks.
  • Synchronized Lyrics: Automatically fetches time-synced lyrics from lrclib.net, embedding them into metadata and saving sidecar .lrc files.
  • Loudness Normalization: Normalizes track audio to standard -14 LUFS (EBU R128) across heterogeneous album releases.
  • On-Disk Duplicate Skipping: Detects existing tracks in your music library and marks them ON DISK, avoiding redundant downloads.

Convert Media

The Convert tab (Ctrl + 5) processes local video, audio, images and animations with FFmpeg and FFprobe. Files stay on this computer.

Once inputs are staged, the Source header shows the selected file, media details and local path above the settings. The large Files section is hidden. Use Add files or Change files to manage inputs; the batch selector changes the displayed source while settings apply to the whole batch.

Choose an output and settings

  • Video: MP4, MKV, MOV and WebM. Automatic copies compatible streams; Encode applies quality settings even within the same format. Stream copy only rejects operations that need encoding.
  • Images and animations: JPEG, PNG, BMP, TIFF, GIF and WebP. MP4 to GIF exports a selected range without audio; GIF to MP4 preserves animation timing. A still image needs an explicit duration to become a video or GIF. Video to JPEG/PNG exports one frame.
  • Audio: MP3, AAC/M4A, ALAC/M4A, FLAC, WAV, AIFF, Opus and Ogg Vorbis. Extract a selected audio track or encode it with bitrate, sample rate, mono/stereo, fades and optional single-pass normalization at -16 LUFS / -1.5 dBTP.
  • Precise controls: timestamps accept seconds or HH:MM:SS.mmm. Maximum width/height preserve aspect ratio without upscaling. GIF settings include frame rate, dithering and loop count; WebP offers lossless encoding. PNG compression changes effort rather than visual quality.
  • Setting help: conversion switches show their names and descriptions. Use the info buttons for explanations of technical settings. GIF dithering help compares Smooth · Sierra, Ordered · Bayer and None. Close the help dialog with Escape or Got it to return to the setting.
  • Presets: start from common settings or save named settings locally.

Review and run

Choose files, drop files or folders, or paste one path per line. Folder scans include two levels and up to 500 files. Review the backend-authored plan and warnings for each source. Convert compatible files; excluded files stay staged. Only outputs supported by the installed tools are offered.

Leave the destination empty to save in a Converted subfolder of the current working folder shown in Downloads. The footer folder picker and its default reset update this destination; Quick convert to MP4 follows the same choice. A custom destination overrides it, and retries keep their original recorded folder. Existing files get unique names. Originals are kept by default. The advanced deletion option removes a source only after the output is verified and the source is checked for changes.

History and settings survive restarts. Interrupted jobs can be retried from the beginning with their original settings and destination. Cancel removes working files; clearing history keeps completed outputs.

In the Downloads table, right-click a supported completed file and choose Convert…. Convert opens with that input highlighted and focused, keeping existing inputs and settings. Repeated selections do not add duplicates, and multi-selection includes only supported completed files. No conversion starts until you choose its settings and press Convert. Quick convert to MP4 remains available for applicable videos.

Lossless output cannot recover detail already lost in a source. Encoded picture output does not preserve HDR or color profiles. Waveform editing, rendered previews, chapters, joining and subtitles are planned separately.

Some FFmpeg builds export animated WebP but cannot decode it. Those inputs are rejected before conversion; static WebP and animated WebP export remain available. Original files are kept when animated output cannot be decoded for verification.

Routing Rules & Automatic Categorization

Configure automated sorting rules under the Rules tab (Ctrl + 7) to route incoming downloads into specific directories based on match patterns.

  • Extension Matcher: Matches file extensions (e.g., iso,img,vhd → D:\Images; zip,rar,7z,tar,gz → D:\Archives).
  • Domain Matcher: Matches source hostnames (e.g., github.com → D:\Code\Releases).
  • Regex Matcher: Evaluates full regular expressions against the complete source URL.
Precedence Rule

When a user explicitly selects a custom save folder in the Add Download dialog or extension prompt, the explicit choice always overrides automatic category rules.

Adaptive FFmpeg Re-Encoding

When Re-encode oversized media to fit is enabled (default), Zoltraak creates a temporary compressed copy for Discord while leaving the pristine full-quality file untouched on your hard drive.

Hardware-Tied Vault Encryption

Your bot token and webhook URL are protected with AES-256-GCM encryption, with the key wrapped by Windows DPAPI on Windows or kept in an owner-only file on other systems in Zoltraak's secure credential vault (zoltraak.discord). Secrets are never exposed in log outputs or plaintext snapshots.

No Account, No License Key

Zoltraak is a standalone app. Install it and everything works: there is no sign-in, invite code, license key, or device activation, and no feature is locked behind a server.

  • Independent of the Zoltraak webserver: No Zoltraak account or running-instance heartbeat is needed. Downloads, online media and Discord delivery still require access to their respective services; local conversion can work offline when its required tools are installed.
  • No usage heartbeat: The app does not send running-instance counts or launch identifiers to a Zoltraak webserver.
  • Updates: The built-in updater still checks the signed release feed on GitHub.

Extension Orders, Video Overlays & Intercept

Troubleshooting & Frequently Asked Questions

Q: Downloads return "HTTP 403 Forbidden" or fail after a few seconds?

Many CDNs generate temporary pre-signed links that expire after a set time. If the link was sent from a browser, ensure the extension is paired so necessary session headers and referrers are attached.

Q: YouTube downloads stall at 2 MB?

YouTube requires signed-in client authentication and a proof-of-origin token (po_token) for full-length streams. Sign into YouTube in your browser with the extension enabled, play any video once to trigger session capture, and retry the download in Zoltraak.

Q: Discord uploads fail with "Payload Too Large" or files are skipped?

Ensure FFmpeg is installed via Settings → General → FFmpeg Media Tools so Zoltraak can re-encode oversized media to fit your server's boost tier ceiling. Also verify that your bot has Attach Files and Send Messages permissions in the target channel.

Q: Browser overlay shows "Extension was reloaded"?

If the Zoltraak companion extension is updated or reloaded in developer mode, active browser tabs lose background message port bindings. Press F5 on the webpage to reconnect the overlay.

Q: Extension shows "Disconnected" or "Cannot connect to local engine"?

Verify that Zoltraak is running. Ensure local port 1450 is not blocked by third-party firewall software. Copy your API token from Settings → Extension and paste it into the extension popup.
